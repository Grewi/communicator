# Алиасы в сообщениях

Алиас, это временная замена имени. По сути, это логин привязанный к сессии, меняем ключ сесии и вместе с ним меняем логин.

Алиас, это единственный идентификатор фигурирующий в заголовках http

Сервер, получая сообщение, ищет в свой базе этот идентификатор и по нему определяет ключ  которым будет расшифровано 
сообщение.

Алиасы используются для предачи любых сообщений, в том числе и для клиентов и для серверов.
