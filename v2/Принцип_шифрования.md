# Принцип шифрования

В данном разделе описываем по какому принципу происходит шифрование данных. Речь идёт именно о внутреннем шировании, 
внутри http и https 

## Обмен ключами
Для установления связи программы должны обменяться публичными ключами.
сервер1 - генерирует простой числовой код и шифрует его своим приватным ключом.
сервер1 - отправляет зашифрованную строку в сервер2 и отдаёт числовой код своему пользователю 
пользователь1 должен самостоятельно сообщить пользователю2 числовой код по другим каналам связи
пользователь2 передаёт числовой код серверу2 
сервер2 с помощью публичного ключа сервера1 расшифровывает код 
**полученный код должен совпасть с кодом полученным от своего пользователя.**

После этого, сервер2 должен отправить свой публичный ключ
сервер2 шифрует полученный цифровой код своим приватным ключом, а полученный результат публичным ключом сервера1 
сервер1 расшифровывает своим приватным ключом, а затем публичным ключом сервера2, 
результат должен совпасть с цифорвым кодом сгенерированным изначально.

если успешно сервер1 отправляет серверу2 сообщение успешного завершения 
иначе код ошибки.


## Дополнительный метод обмена ключами 
Для  этого метода у сервера1 и сервера2 уже должен быть некоторый набор контактов. 
При первом запросе сервер1 должен послать список контактов подходящих для подтверждения. 
Если среди контактов найдётся один или несколько общих, то такой третий контакт выбирается как посредник 
Поскольку у каждого сервера уже есть зашифрованный канал связи с посредником, то обмен публичных ключей идёт через него.

## Создание ключей сессий
Для обмена информацией сервера используют сессионные ключи. Для создания сессионного ключа любой из серверов 
может создать запрос на его создание. 
сервер1 генерирует ключ сессии и алиас, кодирует их публичным ключом сервера2 и отправляет
сервер2 расшифровывает, сохраняет их, генерирует свой алилас, шифрует их публичным ключом сервера2, и отправляет обратно.
сервер1 расшифровывает, сравнивает ключ с оригиналом, алиас сохраняет.
если ключи совпали, отправляет код успешного завершения 
иначе код ошибки.
