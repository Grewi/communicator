# Номера запросов

## Применение
Номер запроса должен использоваться в теле запроса и является основной информацией при передаче данных. 
Номер должен использоваться прилюбой передаче данных от сервера к серверу, от сервера к клиенту и от клиента к серверу 

## Структура 
xxxx-yyyy-zzzz где:
x - Номер документа api 
y - раздел документа 
z - номер операции
