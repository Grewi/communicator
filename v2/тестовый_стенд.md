# Тестовый стенд 

>Тестовая реализация системы коммуникатора для проверки и отладки 

## Что использовать для реализации.

На самом деле, это не так уж и важно. Но есть несколько важных моментов,
которые нужно учесть.
- Язык дложен быть интерпритируемым, правки нужно будет делать быстро, а скорость выполнения вторична
- Язык должен быть распространённым
- Язык длжен быть универсальным и уметь выполнять поставленные задачи.

Наиболее подходящими, для этих целей, я вижу 
- Python, 
- PHP,
- GO
