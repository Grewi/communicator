# Приветственный запрос

Особый тип запроса т.к это единственный запрос-ответ который может не использовать внутренее ширование.

В зависимости от используемого порта ответ может быть в html формате или в формате коммуникатора.

Это запрос на получение основной информации о коммуникаторе.
Ответ зависит от той информации которую готов предоставить владелец, но структура и формат полей 
должны соответствовать документации.

Нужно заложить достаточно большое количество разных структур, подхходящих для частных лиц и разных 
типов организаций. Важно заложить именно разные типы, порядок в структуре может быть разным. Например 
галлерея может быть и внутри описания автора и внутри адреса т.е. тип галлерея может применятся внутри 
разных структур.

Входящий запрос также может содержать некоторую информацию, в зависимости от которой может формироваться ответ.
Наример он может содержать ключ авторизации.

Просто примеры запросов.

Первый запрос к серверу коммуникатора.

name   - Имя коммуникатора отправителя
key    - Публичный ключ
trasts - Страница
