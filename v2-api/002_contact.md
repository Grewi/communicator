# 2 Установление контактов

## 1 Установление контакта от сервера к серверу двухконтактным способом

>Для установления связи программы должны обменяться публичными ключами.
сервер1 - генерирует простой числовой код и шифрует его своим приватным ключом.
сервер1 - отправляет зашифрованную строку в сервер2 и отдаёт числовой код своему пользователю 
пользователь1 должен самостоятельно сообщить пользователю2 числовой код по другим каналам связи
пользователь2 передаёт числовой код серверу2 
сервер2 с помощью публичного ключа сервера1 расшифровывает код 
**полученный код должен совпасть с кодом полученным от своего пользователя.**

>После этого, сервер2 должен отправить свой публичный ключ
сервер2 шифрует полученный цифровой код своим приватным ключом, а полученный результат публичным ключом сервера1 
сервер1 расшифровывает своим приватным ключом, а затем публичным ключом сервера2, 
результат должен совпасть с цифорвым кодом сгенерированным изначально.

>если успешно сервер1 отправляет серверу2 сообщение успешного завершения 
иначе код ошибки.

### 2-1-1 Запрос от клиента на сервер о намерении создать контакт 

>Такой запрос с клиента может быть по ручному вводу хоста или в ответ на полученный запрос 1-3-2

```
{
    "api":"1.0.0",
    "number":"2-1-1"
}
```

### 2-1-2 Ответ сервера клиенту 

>Сервер должен сгенерировать числовой код 

```
{
    "api":"1.0.0",
    "number":"2-1-2",
    "code": 123456
}
```

### 2-1-3 Запрос от сервера1 к серверу2 на пердачу кода

>Перед передачей сервер должен создать хеш  публичный ключ + цифровой код  

hash - хеш
key - публичный ключ

```
{
    "api":"1.0.0",
    "number":"2-1-3",
    "hash":123456,
    "key":123456,
    "host": "examle.ru"
}
```

### 2-1-4 запрос от клиента2 к серверу2 

>Второй клиент должен самостоятельно получить цифровой код от первого клиетна
и создать хеш свой публичный ключ + код получунный от своего пользователя 

host - для какого хоста предназначен номер 
code - цифровой код 

```
{
    "api":"1.0.0",
    "number":"2-1-4",
    "host":"exemple.ru",
    "hash":"123456",
    "key": "123456"
}

```

### 2-1-5 ответ сервера2 клиенту2 

status - результат установления контакта

```
{
    "api":"1.0.0",
    "number":"2-1-5",   
    "status":true,
    "error":"Текст ошибки"
}
```
