В данном случае
    Клиент - сервер инициирующий запрос
    Сервер - сервер отвечающий на запрос



1. Клиент
    а. Поддерживаемые версии TLS
    б. Набор поддерживаемых шифров (cipher suites)
    в. Случайное число для последующего создания ключей
    г. Список доверенных серверов

2. Сервер
    Клиент получает сертификат сервера и проводит его тщательную проверку
    а. Отправляет Server Hello 
    б. Выбранный парамер шифрования
    в. Выбранный довереныый сервер
    г. Сертификат выбранного сервера

3. Клиент
    а. Отправляет свой сертификат
    б. CertificateVerify, содержащее цифровую подпись всех предыдущих сообщений рукопожатия, созданную с помощью закрытого ключа    клиента

4. Сервер
    Сервер, получив сертификат от клиента, выполняет аналогичную проверку
